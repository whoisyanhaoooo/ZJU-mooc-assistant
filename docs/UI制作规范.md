# ZJU-mooc-assistant UI 制作规范

> 适用范围：`ZJU-mooc-assistant`（侧栏入口名「ZJU-mooc-assistant」）插件页面。
> 这份规范约束「按键胶囊」「文本输入框与选择框」「状态胶囊」「栏目圆角」「加载圈」「排版与间距」，实现以 `client.js` 中的 CSS 为准。
> 视觉基线沿用 `ZJU-zhiyun-echo`，并补充了本插件实际使用的「打开页面」按钮、文本字段和加载圈规则。

## 1. 总体原则

- 深色界面为主，使用 DSH 主题 token，不写死大面积深色背景。
- 层级顺序：**卡片容器 → 卡片标题/说明 → 内容行 → 操作按钮**。
- 同一层级只使用一种圆角、一种间距节奏。
- 按钮在卡片右上，状态在收起摘要左下。
- 状态胶囊只表达当前状态，不再放进标题栏右侧和操作按钮混排。
- 默认使用 400 / 600 两级字重，避免 500 造成中文粗细不稳定。
- 所有颜色跟随 DSH 主题变量，不在单个栏目里另写一套配色。

本插件页面按以下顺序组织：

1. 页头：标题、副标题、打开 / 登录 / 刷新；
2. 顶部统计：4 张统计小卡；
3. 课程与筛选：课程下拉、类型筛选、SPOC 数；
4. 左右两列：左侧「章节任务」卡，右侧「账号与登录」「设置」卡；
5. 浮层：计划截止时间日历、下拉选项菜单、toast。

## 2. 按键胶囊（按钮）

### 2.1 基础规格

| 项目 | 普通按钮 | 小按钮 |
| --- | --- | --- |
| 最小高度 | `30px` | `26px` |
| 左右内边距 | `12px` | `8px` |
| 圆角 | `9px` | `9px` |
| 字号 / 字重 | `13px / 400` | `12px / 400` |
| 图标间距 | `6px` | `6px` |
| 行高 | `20px` | `20px` |
| 边框 | `.5px` 半透明 | 同左 |

### 2.2 表面与状态

默认是「半透明玻璃按钮」，不是实心大色块。

```css
/* 中性按钮 */
border: .5px solid color-mix(in srgb, var(--dsw-alias-label-primary) 18%, transparent);
background: color-mix(in srgb, var(--dsw-alias-label-primary) 13%, transparent);
color: var(--dsw-alias-label-primary);
box-shadow:
  0 1px 0 color-mix(in srgb, var(--dsw-alias-label-primary) 12%, transparent),
  0 3px 8px rgb(0 0 0 / .16);
```

| 状态 | 处理 |
| --- | --- |
| hover | 背景加深到约 `21%`，边框加深到约 `28%`，阴影略增强 |
| focus-visible | 使用 `--dsw-focus-ring-color`，`outline-offset: 2px` |
| disabled | `opacity: .45`，`cursor: default` |
| loading | 左侧 12px 加载圈，按钮禁用，文本保持不变 |

### 2.3 语义变体

- **主按钮**（打开中国大学 MOOC、保存设置等）：蓝色半透明玻璃，不用纯蓝实心。
  - 背景 `business 30%`
  - 边框 `business 52%`
  - hover 背景 `38%`、边框 `64%`
- **危险按钮**（取消任务、退出登录）：红色半透明玻璃。
  - 背景 `error 10%`
  - 边框 `error 32%`
  - hover 背景 `16%`、边框 `44%`
- **提示按钮**（「打开页面」等需要人工处理的辅助操作）：warn 色玻璃。
  - 背景 `warn 11%`
  - 边框 `warn 34%`
  - hover 背景 `18%`
  - 仍为 `9px` 圆角，不用 `999px` 胶囊形

所有变体共用：`9px` 圆角、`.5px` 边框、底部高光 + 柔和阴影、`400` 字重。

### 2.4 布局规则

- 按钮统一放在卡片标题栏的**右上角**（`justify-content: flex-end`）。
- 卡片操作按钮之间间距 `6px`；页面顶部按钮行间距 `8px`；任务行内操作按钮间距 `4px`。
- 不要在「读取我的课程」和「展开/收起」之间插入状态胶囊。
- 不要在标题右侧放状态胶囊；状态放到收起摘要的左下角。
- 卡片标题下的操作按钮单独成行时，按钮仍然靠左排列，不和标题抢宽度。
- 任务行右侧固定为「打开页面 → 重试/开始 → 取消」的阅读顺序；打开页面是按钮，不是状态胶囊。
- 按钮文案用动词开头；加载时保留原文本，只在左侧出现加载圈。

## 3. 文本输入框 / 下拉选择框

### 3.1 基础规格

| 项目 | 数值 |
| --- | --- |
| 高度 | `30px` |
| 圆角 | `8px` |
| 左右内边距 | `9px` |
| 字号 / 字重 | `13px / 400` |
| 行高 | `20px` |
| 边框 | `.5px` 半透明 |
| 表面 | 半透明玻璃（`bg-layer-2` 约 `62%`），不用纯 `bg-base` 实心深色 |
| placeholder | `label-tertiary`，不要比正文更亮 |

输入框、下拉触发器、数字步进器必须共用同一套高度、圆角、边框和表面，不能各自写一套。

本插件里适用这套的字段：

- 账号与登录：手机号/邮箱、密码；
- 设置：怎么称呼你、浏览器路径；
- 设置：答题策略、模型思考强度（自定义下拉触发器）；
- 设置：视频倍速、考试尝试次数、浏览器端口、最大执行记录（数字步进器）。

### 3.2 表面与状态

```css
/* 默认：半透明玻璃字段 */
border: .5px solid var(--dsw-alias-border-l2);
border-radius: 8px;
background: color-mix(in srgb, var(--dsw-alias-bg-layer-2, var(--dsw-alias-interactive-bg-hover)) 62%, transparent);
```

| 状态 | 处理 |
| --- | --- |
| hover | 边框提亮到约 `22%`，表面提亮到约 `72%` |
| focus | **不要用 `2px` 硬描边**；边框变 `business 52%`，外加 `3px` 柔和外发光（`business 16%`） |
| 下拉展开 | 与 focus 同一套外发光，不要出现第二种高亮 |
| disabled | `opacity: .5`，`cursor: default` |
| 过渡 | `background / border-color / box-shadow` 统一 `.18s` |

```css
/* focus：柔和外发光，替换原生蓝色 outline */
outline: none;
border-color: color-mix(in srgb, var(--dsw-alias-state-business-primary) 52%, transparent);
box-shadow: 0 0 0 3px color-mix(in srgb, var(--dsw-alias-state-business-primary) 16%, transparent);
```

### 3.3 布局规则

- 输入框占满所在字段列，不写死像素宽度；同一表单内字段宽度一致。
- 字段由「标签 → 控件 → 说明」三段组成，标签在上、说明在下，间距分别为 `5px`。
- placeholder 只放输入示例，不放默认值；默认值放 value，空值提示放说明文字。
- 密码框保持 `type="password"`，不提供「显示密码」以外的额外装饰。
- 数字步进器把输入框和左右按钮包在同一个 `30px` 字段容器里，聚焦高亮只画在容器上。
- 不要在输入框内部再叠加按钮、图标或状态胶囊；需要操作时放到字段右侧或下方。
- 字段为空且有默认行为时，用说明文字解释，不要把默认值写进占位符代替。

### 3.4 数字步进器（Number Stepper）

用于「视频倍速（1–4 倍）」「考试最多尝试次数」「浏览器端口」「最多保留执行记录」这类带 `min / max / step` 的数字设置。

结构固定为：**左 `−` 按钮 + 居中的数值 + 右 `+` 按钮**，三部分包在同一个字段容器里。

```text
[  −  ]          2          [  +  ]
  24×24       13px 居中        24×24
```

| 项目 | 数值 |
| --- | --- |
| 容器高度 | `30px` |
| 容器圆角 | `8px` |
| 容器内边距 | `2px` |
| 容器边框 / 表面 | 与文本输入框完全一致（`.5px` 半透明 + 玻璃表面） |
| 左右按钮 | `24×24px`，圆角 `6px`，透明底 |
| 按钮字符 | `− / +`，`15px / 400` |
| 数值 | `13px / 20px`，`400`，水平居中 |

状态：

| 状态 | 处理 |
| --- | --- |
| hover 容器 | 边框约 `22%`，表面约 `72%`，与文本框一致 |
| hover 按钮 | 背景 `label-primary 8%`，字符从次级色提亮到主文字色 |
| focus-within | 光晕只画在容器上；内部 input `outline: none` |
| 到达最小 / 最大值 | 对应方向按钮禁用，`opacity: .35`，`cursor: default` |
| 整体 disabled | 容器 `opacity: .5` |

行为规则：

- `− / +` 放在字段两端，数值始终屏幕居中，不因数字位数变化而左右跑；
- 点按钮按 `step` 增减，并夹在 `min/max` 内；
- 手动输入后按 Enter 或失焦提交，非法输入回退到上一次合法值；
- 隐藏浏览器原生 number 上下箭头（`appearance: textfield`）；
- 范围写进字段标签（如「视频倍速（1–4 倍）」），默认值和解释写进 hint，不把范围藏进 placeholder；
- 不要在数值后面塞单位后缀，单位放标签或 hint；
- 窄屏下仍占满字段列，不把按钮压到 `24px` 以下。

### 3.5 字段类型怎么选

- 任意文本 → 单行文本框；
- 固定几个选项 → 自定义下拉（触发器同文本框规格）；
- 有范围、可按步长调整的数字 → 数字步进器；
- 多行文本 → 本插件暂不使用 textarea。

## 4. 状态胶囊

### 4.1 基础规格

| 项目 | 数值 |
| --- | --- |
| 圆角 | `999px` |
| 高度 | 由 `line-height: 18px` 决定 |
| 左右内边距 | `7px` |
| 字号 / 字重 | `11.5px / 400` |
| 行高 | `18px` |
| 图标间距 | `4px` |

### 4.2 色调

```css
/* 成功（已完成、已登录、账号可用） */
color: color-mix(in srgb, var(--dsw-alias-state-success-primary) 72%, var(--dsw-alias-label-secondary));
background: color-mix(in srgb, var(--dsw-alias-state-success-primary) 9%, var(--dsw-alias-bg-layer-2, transparent));

/* 警告（需要你操作、待确认、后台执行中） */
color: var(--dsw-alias-state-warn-primary);
background: color-mix(in srgb, var(--dsw-alias-state-warn-primary) 14%, transparent);

/* 错误（失败、登录失效） */
color: var(--dsw-alias-state-error-primary);
background: color-mix(in srgb, var(--dsw-alias-state-error-primary) 12%, transparent);

/* 信息 / 计数 / 待处理（进行中、排队中、任务数） */
color: var(--dsw-alias-state-business-primary);
background: color-mix(in srgb, var(--dsw-alias-state-business-primary) 12%, transparent);
```

成功态要偏柔和：文字用 72% 成功色 + 28% 次级文字色，背景用 9% 成功色叠在 `bg-layer-2` 上。

### 4.3 位置规则

- 收起状态：状态胶囊放在**内容区左下角**，与说明文字同一行。
- 展开状态：状态信息可以进入 facts / 摘要，不再重复放标题栏。
- 同一张卡只保留一个主状态：
  - 账号卡：已登录 → 「已登录」；需要滑块 → 「需要验证」；未登录 → 「未登录」。
  - 课程卡：只显示「2 门」这类数量状态。
  - 设置卡：显示「后台执行 / 可见窗口」等生效状态。
  - 章节任务卡：任务行状态用「未开始 / 进行中 / 需要你操作 / 已完成 / 失败」。
  - 讨论任务：沿用同一状态词，不再额外造一套。
- 禁止把状态胶囊放在按钮之间，或与按钮一起挤在右上角。

## 5. 栏目圆角

| 元素 | 圆角 |
| --- | --- |
| 页面内容卡片 | `15px` |
| 顶部统计小卡 | `15px` |
| 弹窗 / 计划截止时间浮层 | `15px` |
| 下拉菜单 | `12px` |
| 提示条 / toast | `11px` |
| 普通按钮 / 「打开页面」按钮 | `9px` |
| 输入框 / 下拉选择框 | `8px` |
| 下拉选项 | `8px` |
| 复选框 | `6px` |
| 状态胶囊 / 进度条 | `999px` |

原则：

- **容器大圆角，控件小圆角**。卡片统一 `15px`，不要再混用 `13px / 14px`。
- 按钮统一 `9px`，不要混用胶囊形按钮。
- 真正需要胶囊形的只有状态标签、进度条、开关和下拉菜单里的选项。
- 所有圆角都跟随 DSH 主题；不要为单个栏目单独写另一套圆角。

## 6. 排版与间距

### 6.1 字体

```css
font-family:
  "IBM Plex Sans",
  "Segoe UI Variable",
  "Segoe UI",
  "Noto Sans SC",
  "Microsoft YaHei UI",
  "PingFang SC",
  "Microsoft YaHei",
  system-ui,
  sans-serif;
```

- 英文/数字优先 IBM Plex Sans，中文回落 Noto Sans SC。
- 全页使用等宽数字：`font-variant-numeric: tabular-nums`。
- 两级字重：正文/说明 `400`，标题/名称/数值 `600`。

### 6.2 字号阶梯

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | `23px / 31px` | `600` |
| 页面副标题 | `13.5px / 21px` | `400` |
| 卡片标题 | `15px / 23px` | `600` |
| 统计栏标题 | `12px / 17px` | `600` |
| 统计主数值 | `16px / 23px` | `600` |
| 课程/任务名称 | `13.5px / 21px` | `600` |
| 正文 | `13.5px / 21px` | `400` |
| 次级说明、元信息 | `12.5px / 18px` | `400` |
| 更小的提示 | `11.5px / 16px` | `400` |
| 状态胶囊 | `11.5px / 18px` | `400` |
| 按钮 | `13px / 20px` | `400` |

### 6.3 页面结构

- 页面内容最大宽度：`1180px`。
- 页面左右留白：`clamp(18px, 3vw, 44px)`；底部留白 `56px`。
- 顶部标题区纵向排列：
  - `padding: 26px 0 16px`
  - 标题和副标题间距 `6px`
  - 标题块和下方按钮行间距 `14px`
- 顶部四个统计卡：
  - 4 列等宽，间距 `16px`
  - 上边距 `12px`，下边距 `0`
  - 内边距 `11px 13px`
- 主内容区：
  - 左右两列等宽，右列最小 `360px`
  - 横向间距 `16px`，纵向卡片间距 `16px`
  - 与统计区之间间距 `16px`
- 卡片内部：
  - 标题栏内边距 `14px 16px 0`
  - 内容区内边距 `11px 16px 16px`
  - 标题和说明之间 `3px`
- 任务行：
  - 类型胶囊、任务名、状态胶囊、分数胶囊、自动完成胶囊同一行，允许换行；
  - 任务说明在标题下一行；
  - 「计划截止时间」单独一行，位于说明与执行进度之间；
  - 执行中的行内实时进度放在计划时间下方。
- 响应式：
  - 容器宽度 ≤ `880px` 时，两列变一列，统计仍为 2 列。
  - 容器宽度 ≤ `560px` 时，统计变 1 列，标题区顶部内边距收为 `20px`。
  - 窄屏下任务行操作区单独换行，不挤压任务标题。
- 展开/收起时，标题栏和按钮位置保持稳定，只有内容区变化；不要因为文案变长导致标题栏跳动。

## 7. 展开与加载动效

- 展开/收起时长：`.48s`。
- 缓动：`cubic-bezier(.37, 0, .63, 1)`（类高斯 S 曲线）。
- 收起摘要和展开内容使用成对的 `Collapse`，避免切换时闪烁。
- 箭头旋转：`.4s`，与内容同步。
- 按钮 hover 过渡：`.18s`。
- 卡片首次进入：`.42s` 淡入上移。
- 骨架屏和进度条扫光放慢，避免闪烁。
- 支持 `prefers-reduced-motion: reduce`，关闭位移、闪烁和旋转动画。

### 7.1 加载圈（Spinner）

加载圈不是「缺口圆环」，而是**完整暗轨道 + 一小段高亮弧线**。

| 项目 | 数值 |
| --- | --- |
| 形态 | 完整圆环，厚度 `1.4–1.5px` |
| 轨道 | `currentColor` 约 `20%`，始终可见 |
| 高亮弧 | 约 `40deg`，从 `currentColor` 渐变到轨道色，尾部渐隐 |
| 旋转 | `.8s linear infinite` |
| 页面首屏加载行 | `11px`（与旁边 11.5–13px 文字协调） |
| 按钮内 loading | `12px`（小按钮 12px 文字） |
| 默认尺寸 | `13px` |

```css
/* 完整轨道 + 高亮弧，再用径向遮罩挖空中间 */
border-radius: 50%;
background: conic-gradient(
  from 0deg,
  currentColor 0deg 40deg,
  color-mix(in srgb, currentColor 60%, transparent) 78deg,
  color-mix(in srgb, currentColor 20%, transparent) 140deg 360deg
);
-webkit-mask: radial-gradient(farthest-side, transparent calc(100% - 1.5px), #000 calc(100% - 1.5px));
mask: radial-gradient(farthest-side, transparent calc(100% - 1.5px), #000 calc(100% - 1.5px));
animation: mcn-spin .8s linear infinite;
```

- 不要在圆环上留透明缺口，也不要用纯色 `border-top-color: transparent` 的旧转圈。
- 加载圈尺寸跟随旁边文字，不超过文字行高；按钮里用变量 `--mcn-spin-size` 控制。
- `prefers-reduced-motion: reduce` 时停止旋转，保留静止的高亮弧。

## 8. 日历 / 计划截止时间浮层

用于给单个任务设置「计划截止时间」。结构是：**行内触发器 + 浮层卡片（月历 + 时/分滚轮 + 底部操作）**。

### 8.1 触发器

| 项目 | 数值 |
| --- | --- |
| 高度 | `26px`（任务行内紧凑版） |
| 圆角 | `8px` |
| 左右内边距 | `9px / 8px` |
| 字号 / 行高 | `12px / 20px` |
| 边框 / 表面 | 与文本字段同一套：`.5px` 半透明 + 玻璃表面 |
| 后缀 | 未设置时显示「选择截止时间」，已设置时显示 `YYYY/MM/DD HH:mm`，右侧 `Chevron` |

- 未设置时文字用 `label-tertiary`；已设置时用 `label-primary`。
- 触发器宽度跟随内容，不写死；同一任务行里与「清除」按钮间距 `4px`。

### 8.2 浮层卡片

| 项目 | 数值 |
| --- | --- |
| 宽度 | `372px`，最大不超过页面宽度 `- 24px`，最小 `240px` |
| 内边距 | `14px` |
| 圆角 | `15px` |
| 边框 | `.5px solid border-l2` |
| 表面 | `bg-layer-1` |
| 阴影 | `0 20px 48px rgb(0 0 0 / .5), 0 2px 8px rgb(0 0 0 / .2)` |
| 动画 | 打开 `fade-up .16s` 类高斯缓动 |
| 层级 | `z-index: 85`（高于普通内容与设置下拉 82，低于 toast） |

定位规则：

- 默认锚定在触发器**下方**，间距 `8px`；
- 下方空间不足时翻到触发器上方；
- 距页面左右至少 `12px`、距底部至少 `8px`，不超出滚动容器；
- 浮层跟随页面内容滚动，不额外做 fixed 定位。

### 8.3 月历头部

| 元素 | 规格 |
| --- | --- |
| 标题 | `${YYYY}年${M}月`，`13.5px / 20px`，`600` |
| 上/下月按钮 | `26×26px`，圆角 `9px`，`.5px` 边框，透明底，字符 `‹ / ›` `15px` |
| 按钮 hover | 背景提亮，字符变主文字色 |
| 头部与日历间距 | `8px` |

说明文字：`11.5px / 16px`，`label-tertiary`，放在头部下方、日历上方，解释「设置后按顺序自动完成，时间随机落在 8:00–24:00」。

### 8.4 日历格

- 固定 **6 行 × 7 列**，从所在周的**周一**开始；
- 星期表头：一 / 二 / 三 / 四 / 五 / 六 / 日，居中，`11px / 16px`，`label-tertiary`；
- 日期格：高 `30px`，圆角 `8px`，`12px`，格间距 `2px`；
- 非本月日期：`label-tertiary`，`opacity: .55`，仍可点击；
- 今天：`inset 0 0 0 1px` 的 business 色描边，不加填充；
- 选中日期：business 实心底 + 白字，`600`；
- hover：交互背景提亮；
- 月份切换只改变「正在看的月份」，不改变已选日期。

### 8.5 时间滚轮

- 与日历之间用一条 `.5px` 分隔线，间距 `10px`；
- 标题「时间」：`11px / 16px`，`label-tertiary`；
- 两列：时（`00–23`）、分（`00–59`），列间距 `10px`；
- 滚轮高度 `108px`，列表上下各留 `40px` 空白，让选中项能停在正中；
- 选项：`46×26px`，圆角 `8px`，`12px`，居中对齐；
- 选中项：business `16%` 背景 + business 文字 + `600`；
- hover：交互背景提亮；
- 打开浮层时把当前时/分滚到中间，只滚自己的列表，不调用 `scrollIntoView` 连带滚动整页；
- 上下遮罩各 `20px` 渐变，弱化边缘选项；
- 时/分标签：`10.5px / 15px`，`label-tertiary`；分隔符用 `:`，`13px`。

### 8.6 底部操作

- 顶部 `.5px` 分隔线，`margin-top: 12px`，`padding-top: 10px`；
- 左侧：`清除`（文字链接按钮，`12px / 18px`，次级色，hover business）；
- 右侧依次：`今天`、`取消`、`确定`；
- `今天` / `取消` 是文字链接按钮；`确定` 是 primary 小按钮（`26px` 高、`9px` 圆角）；
- 链接按钮之间间距 `6px`。

### 8.7 交互规则

- 点触发器打开浮层，默认值取「下一个整点」（早于 8:00 则取当天 8:00，超过 24:00 顺延到次日 8:00）；
- 点日期只改日期，保留原来的时/分；点时/分只改时间；
- `今天` 把日期改为今天并保留时间；`清除` 关闭浮层并清掉这个任务的计划时间；
- `取消` / `Esc` / 点击浮层外部关闭，不保存修改；
- `确定` 关闭浮层并提交；提交失败或时间已过去，由后端返回中文错误，浮层不再自行猜测；
- 打开浮层时收起课程下拉和其他设置下拉，避免两个浮层同时出现；
- 浮层内所有可点击元素用 `button`；日期按钮带 `aria-pressed`，滚轮列表 `role="listbox"`、选项 `role="option"`，弹层 `role="dialog"` + `aria-label`。

### 8.8 响应式

- 宽度不足时浮层宽度收缩到页面宽度 `- 24px`，最低 `240px`；
- 日历仍是 7 列，日期格高度保持 `30px`，不压缩到不可点；
- 时间滚轮保持「日历在上、滚轮在下」的纵向排列，不改成横向挤压；
- 任务行较窄时，计划时间这一行允许换行；触发器保持单行，不截断已选时间。
